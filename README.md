## 🎯 设立宗旨

独立开发与脑力创造是一场马拉松。长时间盯着终端、连续数十小时心流与碎片化社交互动，极易让神经系统陷入耗竭（Burnout）。

**别累垮（Don’t Burnout）** 从神经科学与工程实战出发，建立一套防崩盘的自我维护协议：
- **深工作时间阻断**：严防碎片化消息打断，保护连续的心流窗口；
- **神经与睡眠恢复**：科学优化睡眠周期与非睡眠深层休息（NSDR）；
- **物理环境配置**：显示器视距、人体工学椅与环境光照的最佳实践。
